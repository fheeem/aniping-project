担当パート（イ・ジョンムン）

本プロジェクトにおいて、アニメーションページ全体のフロントエンド設計および実装を担当しました。

---

1. アニメーション一覧ページ

アニメーションの一覧表示UIおよびユーザー操作機能を実装しました。

主な機能
- アニメーションリスト表示UI
- フィルタリング機能
  - お気に入り（찜した作品）
  - 人気順
  - 最新順
- ジャンル別リストページ構成
- ホーム画面のアニメ一覧レイアウト

---

2. アニメーション詳細ページ

各アニメーションの詳細情報を表示するページのUIおよび構造を担当しました。

主な機能
- PV動画表示エリア実装
- アニメーション詳細情報表示
  - タイトル
  - あらすじ（ストーリー）
  - 登場人物（声優情報含む）
  - 監督情報
  - 画像表示
- いいね（ハート）機能
- お気に入り（찜）機能およびカウント表示
- コメント機能UI
- 通報機能（拡張予定）
- タグ（ジャンル分類）機能（拡張予定）

---
担当ポイント・工夫

- ユーザーが直感的に操作できるUI構造を意識
- アニメ検索・閲覧体験を考慮した画面設計
- コンポーネント単位での機能分離を意識
- 拡張性を考えた機能設計（コメント・タグ・通報など）
